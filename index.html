Reading, Not Reasoning

内化式 Agentic 视觉推理的因果忠实性审计
GitHub ↗
背景

CoT 监督微调将 Agentic 视觉推理压进单次前向 VLM，但准确率提升是否真正内化了推理能力？

方法

Lanham 式因果干预——篡改 CoT 中间量，对比格式对照，强制模型作答并追踪答案来源。

核心结论

CoT 蒸馏稳定提升准确率（ChartQA +6.5pp），但思维链不承载因果——模型在读图而非推理。

It's the Elicitation, Not the Eyes

VLM 作为质检 Critic 的感知 vs 表达归因
GitHub ↗
背景

VLM 常作为 Slide/文档 Agent 的质检 Critic，却频繁放过文字溢出边框缺陷——感知失败还是表达失败？

方法

以无损几何 oracle 为归因基准；对"格式抑制"类，冻结模型仅改 elicitation 测能否恢复检测。

核心结论

覆盖率 2/9 → 8/9（balanced acc. 0.86），跨 6 个 VLM 中 4 个复现，问题在表达而非感知。
